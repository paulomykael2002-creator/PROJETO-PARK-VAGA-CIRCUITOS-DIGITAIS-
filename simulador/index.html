ParkVaga – simulação do circuito montadoLigue a fonte, carregue 6 e use “Entrar um carro” / “Sair um carro”. O carro passa pelo sensor, o contador muda e ele estaciona (ou sai) de uma vaga.

Protoboard 760 – placa lógica (como foi montada: 7 CIs, 52 fios, 7 resistores do display)

Bolinhas S1–S8 = entrada dos sensores · P1–P22 = fios que vão para a placa do visor. Durante a simulação elas mostram o nível lógico do furo: ● amarelo = 1 · ● azul = 0.

Como os sensores de entrada e saída contam: o TCRT5000 dá DO = 1 sem carro e DO = 0 com o carro em cima.

Entrada (SE): quando o carro passa, SE vai de 1 para 0 e volta para 1. Nessa volta, DOWN = SE + L sobe e o 74LS192 desconta 1, então o display mostra uma vaga a menos. Se estiver lotado (L = 1), o DOWN fica preso em 1 e não conta.

Saída (SS): mesma coisa no UP = SS + QC·QB, e o contador soma 1. Se o display já estiver em 6, QC·QB = 1 trava o UP.

Os sensores das vagas só acendem os LEDs (vermelho/verde, HÁ VAGA, LOTADO). Quem muda o número do display são os sensores de entrada e saída.

Sinais lógicos (1 = nível alto, 0 = baixo)

L = S1·S2·S3·S4·S5·S6 = – (lotado)
D = S1'+S2'+…+S6' = – (há vaga)
DOWN = SE + L = –   UP = SS + QC·QB = –
